# 서비스 요구사항

## 목적

DuoAsset은 **부부 2인 전용 자산관리 서비스**다. 일반 가계부가 아니라 부부의 수입·지출·저축·자산·부채·미래 재무계획을 한곳에서 관리한다.

- 매일 지출을 적지 않는다. **월 단위**로 재무 상태를 관리한다.
- 핵심 목표: **매월 5분 정도의 입력**으로 가계 전체의 재무 상태와 미래 자산 전망을 파악한다.
- 사용자는 부부 두 명뿐이다. 불특정 다수 대상 기능은 만들지 않는다.

## 확정된 방향

- 개인 자산·수입·지출은 부부 간 전체 공개
- 입력은 월별 Summary 중심
- PWA + 반응형 웹 (Android, iOS, PC 동일 서비스)
- 각자 계정으로 로그인, 같은 가계 데이터 공유, 클라우드 저장·동기화
- 한국어 UI, KRW, Asia/Seoul, Light/Dark 모드

## 개발 원칙

- 오버엔지니어링하지 않는다. 가독성과 직관성 우선. 불필요한 추상화·계층·검증을 만들지 않는다.
- 단, 금융 데이터 정합성·인증·접근권한에 필요한 검증은 반드시 한다.
- 특정 사용자의 급여·자산·지출 항목을 하드코딩하지 않는다. 모든 재무 설정은 UI에서 추가·수정·비활성화한다.
- 기능뿐 아니라 사용자 경험과 디자인 완성도를 중요하게 본다.

## 사용 시나리오 (구조)

실제 금액은 저장소에 기록하지 않는다. 구조만 남긴다.

- **본인 월급**: 실수령액에서 부모님께 드리는 용돈·이자(정액), 자동차 무이자 할부금, 공용통장 입금액을 빼고 남은 금액을 개인 생활비와 추가 저축에 쓴다. 회사 식비 카드(비현금 복지)가 따로 있다.
- **배우자 월급**: 실수령액에서 공용통장 입금액, 개인 적금·계 모임 납입액을 빼고 남은 금액을 개인 생활비로 쓴다.
- **공동 자금**: 각자 개인통장에서 공용통장으로 일정액을 이체한다. 공용통장에서 주거비·관리비·외식비·생활비를 쓰고, 남은 금액은 공동저축이 된다.
- **자산**: 개인통장, 공용통장, 현금, 예금·적금, 주식, 퇴직연금, 계 모임, 임대보증금, 아파트 분양 납부금, 자동차.
- **부채**: 자동차 60개월 무이자 할부(매월 원금 감소), 부모님 차용금(원금 상환 계획 없이 매월 정액 지급), 향후 주택담보대출.
- **미래 계획**: 신규 아파트 입주, 이직·연봉 인상, 출산·육아, 자동차 할부 종료, 더 넓은 아파트로 갈아타기, 비상금 확보, 장기 순자산 목표.

## 기능 요구사항

### 홈 대시보드

접속하면 가계의 현재 상황을 한눈에 파악한다. 중요한 정보가 먼저 보여야 한다.

총자산, 총부채, 순자산, 가용자산, 부부 합산 월수입, 이번 달 예상 저축액, 실제 저축액, 저축 목표 달성률, 개인별 사용 가능 금액, 공동생활비 현황, 전월 대비 자산 증감, 월별 자산 변화 그래프, 주요 예정 지출 및 미래 이벤트.

### 월급 및 자금 배분

부부 각자의 수입·지출 구조를 설정하면 매월 사용 가능한 금액을 자동 계산한다.

- 개인별 월급, 급여일, 상여금·기타 수입, 회사 복지·비현금성 지원
- 개인 고정지출, 공용통장 납입액, 개인 저축액, 추가 저축액, 개인 사용 가능 금액
- 반복 항목의 적용 시작일·종료일
- 개인과 공동 자금 흐름을 명확히 구분한다. 개인통장에서 나가는 할부금을 공동생활비에 넣거나 중복 차감하지 않는다.
- 계획을 바꾸면 개인 잔여금, 공동저축액, 합산 저축액이 즉시 갱신된다.
- 월별 계획과 실제를 구분한다.

### 공용통장

개인별 예정·실제 입금액, 공동생활비 예산·실제, 월초·월말 잔액, 월별 공동저축액, 주요 공동지출 항목, 다른 계좌로 이동한 금액, 이전 달과의 비교.

공용통장 입금과 공용통장→적금 이동은 소비가 아니라 내부 자금 이동이다. 일별 거래내역 입력을 강제하지 않는다.

### 월별 정산 (핵심)

월말이나 다음 달 초에 한 번 정산한다. 필요한 경우에만 입력한다: 실제 월급·기타 수입, 개인 계좌 잔액, 공용통장 잔액, 실제 공용통장 입금액, 주요 고정지출 납부액, 적금 납입액, 주요 추가 지출, 계좌 간 자금 이동, 투자자산 평가금액, 부채 잔액.

- 가능한 항목은 자동 계산한다. 이전 달 마감 잔액이 다음 달 시작 잔액이 된다.
- 결과: 총수입, 실제 소비지출, 대출 원금 상환액, 실제 저축액, 저축률, 계획 대비 실적, 총자산·순자산 변화, 투자 평가손익.
- 잔액만으로 지출과 자금 이동을 구분할 수 없으면 최소한의 추가 정보만 요청하거나 **미분류 금액**으로 표시한다. 임의로 확정하지 않는다.
- 월 마감, 과거 월 조회·수정 기능. 현재 설정을 바꿔도 과거 확정 데이터는 자동으로 바뀌지 않는다.

### 통합 자산관리

현금성 자산, 예금, 적금, 주식·투자자산, 퇴직연금, 부동산, 임대보증금, 분양 납부금, 자동차, 기타. 유형은 확장 가능해야 한다.

자산별: 이름, 소유자, 현재 평가금액, 취득금액·투자원금, 유형, 유동성, 만기일, 평가 기준일, 메모.

주식은 종목별 실시간 시세가 아니라 계좌 단위(또는 원하는 단위)로 원금과 평가금액만 관리한다. 월별 평가금액을 기록하고 추이를 그래프로 본다.

### 부채 및 장기 고정지출

일반 고정지출, 무이자 할부, 이자 있는 대출, 원금균등, 원리금균등, 원금 상환 없이 정액만 지급하는 차용금, 만기일시상환.

최초 원금, 남은 원금, 월 납부액, 원금·이자 구분, 이율, 납부 기간, 시작·종료일, 납부 담당자, 출금 계좌. 할부·대출이 끝나면 월 가용 자금이 얼마나 늘어나는지 보여 준다. 예정 상환과 실제 상환을 구분한다.

### 목표

목표 이름, 금액, 날짜, 현재 확보 금액, 연결 자산, 월별 적립 계획, 달성률, 예상 달성 시점.

같은 자산을 여러 목표에 중복 배정해 가용금액이 부풀려지지 않게 한다. 목표는 자산이 아니라 자산의 사용 목적이다.

### 미래 자산 시뮬레이션

현재 자산과 월 저축 계획을 바탕으로 미래를 시뮬레이션한다. 사용자가 바꿀 수 있는 조건: 월 저축액, 연봉 인상률, 생활비 증가율, 예상 투자수익률, 미래 소득 변화, 미래 고정지출 변화, 일회성 지출, 대출 발생·종료, 주택 입주, 출산·육아휴직, 차량 할부 종료.

미래 이벤트를 특정 월에 등록해 그 시점부터 반영한다. 현금성 자산·총자산·부채·순자산의 변화를 본다. 기본 시나리오와 수정한 시나리오를 비교한다. 시뮬레이션은 실제 데이터에 영향을 주지 않는다.

## 재무 계산 원칙

1. 개인통장 → 공용통장 이체는 소비가 아니다.
2. 적금 납입은 자산 간 이동이며 소비가 아니다.
3. 대출 원금 상환은 현금 감소와 부채 감소를 동시에 일으킨다.
4. 대출 이자와 일반 소비지출은 순자산을 줄인다.
5. 원금 상환이 없는 정기 지급(부모님 차용금)도 관리할 수 있어야 한다.
6. 비현금성 복지는 현금 수입이나 자산에 포함하지 않는다.
7. 투자 평가손익과 근로소득 저축 성과를 분리한다.
8. 총자산, 순자산, 가용자산, 저축액, 현금 흐름을 각각 명확히 정의한다.
9. 하나의 자산·부채를 중복 집계하지 않는다.
10. 미확인 금액과 실제 0원을 구분한다.
11. 예정 데이터와 실제 데이터를 구분한다.
12. 과거 확정 데이터는 현재 설정 변경으로 바뀌지 않는다.
13. 금액 계산에 부동소수점 오차가 없어야 한다.
14. 원금 상환을 통한 순자산 개선과 저축을 통한 금융자산 증가를 구분한다.
15. 계 모임 등 특수 항목은 성격에 따라 자산·부채·지출로 관리할 수 있다.

구현 방식은 [finance-rules.md](./finance-rules.md)에 있다.

## UI/UX

- Modern · Minimal · Premium · Clean · Financial Dashboard · Mobile First
- 금액, 자산 변화, 저축 성과, 목표 달성률을 강조한다. 과한 그라데이션·장식 아이콘·애니메이션, 과도한 카드 나열, 정보 반복을 피한다.
- 모바일: 한 손 조작, 하단 내비게이션, 간편한 금액 입력, 직관적인 월 전환, PWA 설치, 다양한 화면 크기, 한국어 금액 표현.
- PC: 넓은 대시보드, 사이드바, 자산 변화 그래프, 월별 비교, 상세 자산·부채 관리, 시뮬레이션.

## 인증과 보안

부부 각자 독립 계정, 같은 가구끼리만 공유, 공개 회원가입 비활성화, 비인증 접근 차단, 서버·DB 수준 권한 검증, RLS, HTTPS, 비밀키 노출 방지, 금융 계좌 비밀번호·인증서 저장 금지, 실제 개인정보 커밋 금지, 동시 수정으로 인한 데이터 손실 방지, 백업·내보내기, PWA 캐시에 민감 데이터 미보관, 로그아웃 시 금융정보 미노출.

## 만들지 않는 것

은행 실시간 연동, 카드 승인내역 수집, 마이데이터, 영수증 OCR, 주식 실시간 시세, AI 소비 분석·챗봇, 커뮤니티, 광고, 구독 결제, 불특정 다수용 기능, 복잡한 관리자 페이지, 네이티브 앱, 마이크로서비스, 오프라인 동기화.
